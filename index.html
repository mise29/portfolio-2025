Diary Web App

Diary Web App
日記アプリ｜わたしの心の日記

公開ページ
https://heart-diary-be36f.web.app/

日記Webアプリの構成、デザイン、実装をおこないました。
自分の気持ちや、小さな「できたこと」を記録できます。
自分自身の頑張りを肯定できるような場所を目指して、一つひとつ丁寧に構築しました。

ターゲット
新しい環境に身を置いて頑張っている人/気持ちが落ち込みやすい時期にいる人/日々の小さな前進を、目に見える形で記録・共有したい人/ある目標に向かって記録したい人/日々を綴りたい人など

目的
「今日はこれができた」「○○をやってみた」など、日々の小さな前進に目を向けるきっかけを提供すること
感情や行動を可視化し、自分の頑張りを「見える形で貯金」できるしくみを作ること
気軽に気分やできたことを共有し、共感しあえる場を提供すること

情報設計
日記投稿は、日付・できたこと・学び・明日の目標・感情（画像選択式）の5項目に沿って記録ができます。
また、書き忘れ防止のために、昨日の日付のみ戻って記録することができます。

デザイン
続けてもらいやすいよう、やわらかく親しみやすい配色とフォントを選びました。
「自分のために書く日記」だからこそ、画面全体が安心できる雰囲気になるように意識しています。

制作期間
企画・設計：1日
デザイン：1日
実装：11日
デプロイ・修正・スマホ最適化：1日

使用ツール
HTML / CSS / JavaScript (jQuery) / Firebase / Figma/ Canva

HairSalon Recruit Site

HairSalon Recruit Site
Ray美容室｜採用サイト

公開ページ
https://ray-recruitment.pages.dev/

Ray美容室の採用サイトを制作させていただきました。
クライアントさまの抱く自店のイメージをデザインで表現し、ターゲットとする方々に細部まで目を通してもらえるよう、心掛けて制作しました。

ターゲット
美容業界でのキャリアスタート、新しい挑戦やキャリア向上の機会を求めている人々

目的
求職者に必要な情報を整理し、ブランドとしての魅力や安心感を伝えることに重点をおきました。
応募プロセスへの導線を明確にし、働く姿がリアルに想像できるUI設計・構成に仕上げています。

情報設計
メニュー構成は「ポジション別採用情報」「職場環境」「スタッフインタビュー」「会社概要」など、目的別にブロック化しています。
重要な採用フローや給与・制度は視認性の高い構造で配置し、求職者が迷わず情報を吸収できるよう工夫しました。
また、イントロやインタビューを随所に入れ、感情に訴える読みやすさと一体感を高めました。

デザイン
全体に統一感のあるカラーと見やすい余白を採用。文字は十分な行間を確保し、情報が詰まりすぎないよう配慮しました。
CTAのボタンやインタビューは差し込みレイアウトで構成し、読者の視線と行動を自然に誘導しています。
特にスタッフの声や現場の写真を大胆に見せ、「実際に働くイメージ」に繋げる演出を意識しました。

制作期間
企画・ワイヤーフレーム：2日間
デザイン：5日間
：1週間

HTML / CSS / JavaScript / Figma

Logo Design
ロゴマーク｜小樽市おもてなし規格認証制度

北海道小樽市おもてなし認証制度のロゴマークを制作しました。
小樽市の皆様から直接「小樽市について」をお話いただき、それに基づいて自ら深堀してリサーチを重ね、小樽市の象徴とおもてなしの双方が1つのロゴマークから読みとれることを課題とし、デザインしました。

ターゲット

デザイン
小樽市の自然の美しさとガラス伝統をマッチさせ、一目見て海をメインに、水面を描いたステンドグラスだと分かるロゴ​にしました。また、緩やかな波と握手のデザインで、人々の穏やかな交流とおもてなしを表現しました。
